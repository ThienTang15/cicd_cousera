
# CI/CD Final Project - Python

## Project Overview

This project demonstrates Continuous Integration and Continuous Delivery
(CI/CD) for a Python application using GitHub Actions, Tekton, and OpenShift.

## Technologies

- Python
- GitHub Actions
- Tekton
- OpenShift

## Project Objectives

- Automate code linting and unit testing
- Build a CI workflow with GitHub Actions
- Implement a CD pipeline using Tekton and OpenShift
- Deploy the Python application
